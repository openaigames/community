# 投稿模板 / Contribution templates

复制对应模板到投稿目录，填写后提 PR。可以直接提交，不必先开 Issue；内容使用中文或英文均可。
Copy the relevant template to a contribution directory, fill it in, and open a PR. An Issue is optional; write in Chinese or English.

| 内容 / Content | 模板 / Template | 路径 / Destination |
| --- | --- | --- |
| 点子 / Idea | [idea.md](idea.md) | `ideas/<short-name>/README.md` |
| Demo | [demo.md](demo.md) | `demos/<short-name>/README.md` |
| 工具需求 / Tool need | [tool-need.md](tool-need.md) | `tooling/<short-name>/README.md` |

`<short-name>` 使用简短、稳定的小写英文名，单词之间用连字符。后续更新同一份记录。
Use a short, stable lowercase name with hyphens between words for `<short-name>`. Update the same record for later versions.
