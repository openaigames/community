# 工具需求 / Tool needs

这里保存从真实游戏制作中提炼、通过 PR 合入的工具需求与验证思路。
This directory keeps tool needs and validation plans drawn from real game development and merged through PRs.

复制 [tool-need.md 模板](../templates/tool-need.md)到 `tooling/<short-name>/README.md`，填写后提交 PR。
Copy the [tool-need template](../templates/tool-need.md) to `tooling/<short-name>/README.md`, fill it in, and open a PR.

先写清楚问题、关联作品和预期改善，再讨论具体实现。
Describe the problem, related work, and intended improvement before discussing implementation.
