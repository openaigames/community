# 游戏点子 / Game ideas

这里保存通过 PR 合入的游戏点子与共创计划。首批点子征集中。
This directory keeps game ideas and collaboration plans merged through PRs. First submissions are welcome.

复制 [idea.md 模板](../templates/idea.md)到 `ideas/<short-name>/README.md`，填写后提交 PR。
Copy the [idea template](../templates/idea.md) to `ideas/<short-name>/README.md`, fill it in, and open a PR.

有相关讨论时链接原始 Issue；后续继续更新同一份文档。
Link a related Issue when available and update the same record as the idea evolves.
