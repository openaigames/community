### 一个点子，可以在这里长成游戏。

这里是 **OpenAIGames 的共创空间**。带着想法来，留下能玩的 Demo；找到一起做的人，也给别人的作品一次认真的试玩。

**[带一个点子来 ↗](https://github.com/openaigames/community/issues/new?template=01-game-idea.yml)**　·　**[提交可试玩 Demo ↗](https://github.com/openaigames/community/issues/new?template=02-game-demo.yml)**

[浏览点子](https://github.com/openaigames/community/issues?q=is%3Aissue%20label%3Aidea)　·　[试玩 Demo](https://github.com/openaigames/community/issues?q=is%3Aissue%20label%3Ademo)　·　[作品索引](SHOWCASE.md)　·　[参与方式](CONTRIBUTING.md)

### 让创作持续下去

| 来到这里时 | 留下一点什么 | 接下来一起做 |
| --- | --- | --- |
| 有一个想法 | 核心互动、最小可玩版本、需要的帮助 | 找搭档，做第一版 |
| 有一个 Demo | 试玩链接、操作方式、最想听到的反馈 | 试玩，交流，继续迭代 |
| 遇到反复出现的问题 | 制作场景、当前步骤、关联的 Demo | 判断需求，研发自己的工具 |

游戏点子和 Demo 都用 Issue 记录，分别带上 `idea` 和 `demo` 标签。试玩反馈、版本更新和协作认领留在对应的 Issue 下。Demo 做出来后，链接回原来的点子，让制作过程可以被追溯。

### 从真正的制作中发现工具需求

做游戏时遇到重复、费时的步骤，可以[记录一个工具需求](https://github.com/openaigames/community/issues/new?template=03-tool-need.yml)。先说清楚具体问题、关联作品和希望改善的结果，再一起决定做什么。

### 关于这个仓库

`community` 沉淀点子、作品投稿、试玩反馈和协作记录。正式游戏与工具的代码，在项目确定后放到各自的仓库，并链接回这里。

作品索引从真实投稿开始整理。欢迎第一个可玩的版本，不用等到它完美。
